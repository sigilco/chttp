# stream AGENTS.md

`@chttp/stream` is SSE and chunked text streaming for `@chttp/router`, authored in the scriptc compilable subset. Same subset rules as `packages/router/src` (see root AGENTS.md), plus what this package learned:

- Depends only on `@chttp/router` (peer, workspace devDependency). It imports `Ctx` as a type from `@chttp/router/src/index.ts`; slices never import each other.
- Helpers are free functions taking `Ctx` (`streamSSE`, `streamText`). They `writeHead`, `flushHeaders` and set `c.sent = true` before returning `fn(stream)`; a settled handler that wrote nothing would otherwise get a 500. A promise returned by `fn` flows into the router's `settleChain`.
- Strategies are subclasses (`ChunkStream` > `SSEStream`, `TextStream`), never records of functions.
- Use `s.charAt(i)`, never `s[i]` (SC1090). Named imports from `node:http` only. Guard `T | undefined` explicitly (`x !== null && x !== undefined`).
- `scriptc < 0.3.2` had no backpressure: `write()` result, `"drain"`, `writableLength` and write callbacks were all refused. On 0.3.2+ a compiled `Writable` subclass (runtime-owned surface; never override `push`) wraps `res` and observes the real queue. `ServerResponse` itself still refuses `drain`/`writableLength`/a boolean `write()` (probe-verified again on 0.4.7: `res.write(...)`'s result is SC1090-refused and `writableLength` is SC0001), so the wrapper — not `res` — is the backpressure surface. The pending-bytes window cap stays as the secondary fail-safe.
- A subclassed `_write` does not pump when the class ships inside a statically compiled npm package: `write()` buffers forever and returns false. `ResWriter` probes the pump at construction (swallowed sentinel chunk) and falls back to direct sink writes; see `bench/scriptc-evidence/ws-backpressure-package-mode-2026-10-15.txt`. In that fallback the probe keeps `writableLength` at 1 forever — don't read it as a backpressure signal there.
- A `Ctx` parameter only lowers when a call site gives it a concrete instance, so `scriptc coverage` on `src/index.ts` alone reports unreached code. The gate is `scriptc coverage bench/apps/chttp-stream.ts`, which must stay 100% static. Compiling `src/index.ts` as the entry needs `--npm-static @chttp/router` or the in-tree relative graph; a missing DOM name on the router side surfaces as SC0001, which is why router names no DOM stream types in shared source.
- `pnpm --filter @chttp/stream test` runs the node:test suite against the tsc build with real HTTP round-trips. The compiled path is smoked by building `examples/sse-clock` and `curl -N` (events at the interval; the interval must stop after disconnect).
